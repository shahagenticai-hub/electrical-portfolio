Sheet 01 of 04 · Final-year projectBuilt and deployed

Smart OLTC Transformer Monitoring System

An on-load tap changer controller for a transformer, built on solid-state relays instead of mechanical contactors. An Arduino Mega reads voltage through ZMPT101B sensors and decides when to change tap. An ESP32 sends the readings to a Flutter Android app.

On top of the live data sits a local language-model chatbot (Ollama, phi3) that answers questions using the current sensor values, and an Isolation Forest model that flags abnormal readings.
